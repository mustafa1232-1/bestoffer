# AI DEV SUPPORT Dashboard Guide

## Open screen
- Login as `super_admin`.
- Open Admin Dashboard.
- Open `AI DEV SUPPORT` from Operations group.

## Tabs
- Overview
- Incidents
- Pending Approvals
- Code Fix Requests
- Notifications
- Settings

## Incident flow
1. Review incident details.
2. Create GitHub issue if needed.
3. Request code fix.
4. Approve or reject proposed action.
5. Mark incident resolved.
