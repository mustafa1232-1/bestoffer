# Incident Response Runbook

## Detection
- Alerts from Sentry/Datadog/Railway/GitHub Actions/webhooks

## Triage
- Severity: SEV1..SEV4
- Risk: low/medium/high/critical
- Redacted logs only

## Action
- Create action proposal
- If medium/high/critical: pending approval
- High/Critical: typed confirmation required

## Closure
- Validate stability
- Mark resolved
- Keep audit trail
