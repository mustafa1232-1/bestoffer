# Final Release Checklist

Use this checklist on a clean build after deploying release artifacts.

## Accounts

- [ ] Log in as customer.
- [ ] Log in as store owner.
- [ ] Log in as store employee with permissions.
- [ ] Log in as restricted store employee.
- [ ] Log in as delivery.
- [ ] Log in as service provider.

## Core Flow

- [ ] Create order.
- [ ] Accept order.
- [ ] Mark item unavailable.
- [ ] Assign delivery.
- [ ] Delivery accepts.
- [ ] Complete order.

## Notifications

- [ ] Verify customer notification tap opens the correct screen.
- [ ] Verify store notification tap opens the correct screen.
- [ ] Verify delivery notification tap opens the correct screen.

## Reports

- [ ] Check owner report.
- [ ] Export PDF.
- [ ] Export Excel.
- [ ] Check settlement summary.

## Pharmacy / Services

- [ ] Create service request.
- [ ] Service provider receives notification.

## Permissions

- [ ] Verify restricted employee is blocked from protected actions.
