# دليل مركز الصيانة (Admin Maintenance Center)

## الهدف
صفحة **مركز الصيانة** داخل لوحة الأدمن تعطيك تشخيص سريع + إجراءات إصلاح فورية بدون الدخول للكود.

المكان:
- `لوحة الأدمن -> App Drawer -> مركز الصيانة`

## ماذا تفحص الصفحة
1. **اتصال الخادم**: فحص `/health`.
2. **واجهات الأدمن**: فحص API التحليلات.
3. **منظومة الإشعارات**: unread + حالة realtime.
4. **مجتمعات شديصير بسماية**: التأكد من جلب نطاقات المجتمع.
5. **سلامة النص والترميز**: اكتشاف النصوص المشوهة ضمن عينة الإشعارات.

الحالات:
- `OK`: سليم.
- `Warn`: يحتاج متابعة.
- `Fail`: عطل واضح يجب إصلاحه.

## أزرار الصيانة
1. **صيانة سريعة تلقائية**
- يعيد ربط realtime للإشعارات.
- يعيد تحميل بيانات الأدمن والإشعارات.
- يعيد تشغيل الفحص الشامل مباشرة.

2. **إعادة ربط الإشعارات**
- `stop/start` للـ realtime stream.
- تحميل unread + قائمة الإشعارات.

3. **تحديث بيانات الأدمن**
- إعادة `bootstrap` للوحة الأدمن.
- مزامنة فورية للقوائم والأرقام.

## آلية العمل القياسية قبل كل نشر
1. افتح مركز الصيانة.
2. نفّذ **إعادة الفحص**.
3. إذا ظهر `Warn/Fail` نفّذ **صيانة سريعة تلقائية**.
4. أعد الفحص مرة ثانية.
5. لا تنشر إلا إذا كانت النتائج مستقرة.

## صيانة اللغة والترميز
إذا ظهر تشوّه نص:
1. نفّذ الصيانة السريعة.
2. أعد فتح الشاشة المتأثرة.
3. إن بقيت المشكلة، افحص البيانات المصدر في DB (غالبًا البيانات دخلت بترميز خاطئ).

## ملاحظات تشغيل
- مركز الصيانة لا يحذف بيانات إنتاج.
- كل الإجراءات آمنة ومناسبة للبيئة الحية.
- للأعطال العميقة (SQL migration / schema) استخدم أدوات الباك‑إند مع سجل التدقيق.
