# نقاط مرجعية للتطوير

## نقطة رقم 1
**الاسم:** الكود يعمل بشكل صحيح تمامًا  
**الوصف:** مرجع العودة إلى نسخة منطقية مستقرة مع:
- ربط الإشعارات بصفحاتها الأساسية
- صفحة منشورات تحتاج تعديل
- تثبيت بحث المستخدمين وطلبات الصداقة في شديصير
- إظهار بوابة الموظف فقط للمستخدم المعيّن
- عزل أقسام المتاجر داخل الهَبّات عبر فلاتر البحث الأولية

> عند طلب "العودة إلى نقطة رقم 1" يتم اعتماد هذه المرجعية كأساس.
