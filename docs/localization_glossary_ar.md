# معجم التعريب العربي

## الهدف
هذا الملف هو المرجع الرسمي لنصوص الواجهة العربية في تطبيقات **مسلكي**.
أي نص يظهر للمستخدم يجب أن يلتزم بهذه المصطلحات داخل ملفات `ARB` فقط.

## المصطلحات المعتمدة
- `BestOffer / Maslaki (brand in Arabic UI)` => `مسلكي`
- `Store` => `متجر`
- `Create Store` => `إنشاء متجر`
- `Store Account` => `حساب متجر`
- `Store Owner` => `صاحب المتجر` في السياق الإداري
- `Merchant` => `صاحب المتجر` أو `تاجر` في السياق الإداري فقط
- `Reels` => `ريلز`
- `Coupon` => `كوبون`
- `Filter` => `فلتر`
- `Live` => `لايف`
- `Activity Type` => `نشاط المتجر`
- `Category` => `تصنيف`
- `Saved Places` => `الأماكن المحفوظة`
- `Favorite Trips` => `الرحلات المفضلة`
- `Delivery` => `دلفري` أو `مندوب توصيل` حسب السياق
- `Captain` => `كابتن`
- `Taxi` => `تكسي`
- `Search` => `بحث`
- `Orders` => `الطلبات`
- `Home` => `الرئيسية`

## مصطلحات ممنوعة
- `مسلقي`
- `مسكلي`
- `بكرات` في سياق Reels
- `إنشاء تاجر` داخل تدفقات إنشاء المتجر

## قواعد الإلزام
- كل النصوص الظاهرة للمستخدم تدار من `lib/l10n/*.arb`.
- يمنع وضع نص عربي hardcoded داخل ملفات الواجهات.
- أي تعديل جديد يمر على مراجعة اتساق المصطلحات.
