# شفرة الفريق: دليل التشغيل والاختبار

هذه الميزة مخصصة حاليًا للبيئة المحلية وبيئة الاختبار فقط. حملة اللعبة
الافتراضية تستخدم مكافأة تجريبية ولا تنشئ كوبونًا أو رصيدًا حقيقيًا.

## الإعداد المحلي

1. شغّل PostgreSQL واضبط متغيرات `backend/.env.test` أو بيئة التطوير.
2. طبّق الهجرات واملأ بنك الألغاز:

```powershell
cd backend
npm install
npm run migrate:sql
npm run seed:team-code
```

3. شغّل API:

```powershell
cd backend
npm run dev
```

4. شغّل تطبيق المستخدم:

```powershell
flutter pub get
flutter run
```

5. افتح القائمة الرئيسية ثم اختر `ألعاب مسلكي` ثم `شفرة الفريق`.

## اختبار فردي سريع

1. اختر اللعب الفردي وابدأ اللعبة.
2. تأكد أن الجولة تعرض التلميحات فقط ولا تعرض الحل.
3. اطلب تلميحًا، ثم أعد الطلب نفسه عند محاكاة إعادة الإرسال؛ يجب ألا يخصم
   أكثر من تلميح واحد.
4. أدخل رمزًا خاطئًا وتأكد من نقص محاولة واحدة فقط.
5. بعد نجاح الخزنة الأولى، اطلب المكافأة التجريبية مرتين؛ ينجح الطلب الأول
   ويرفض الثاني.
6. أكمل الجولات الثلاث وتأكد من ظهور حلول الجولات التي لُعبت وشروحها فقط.

## اختبار تعاوني بجهازين

1. أنشئ غرفة من الحساب الأول وشارك رمز الغرفة المكون من ستة أحرف.
2. انضم من الحساب الثاني، وتأكد أن كل لاعب يرى تلميحاته الخاصة فقط.
3. اجعل اللاعبين جاهزين، ثم ابدأ من حساب المضيف.
4. أرسل رسالة وعبارة سريعة، وتأكد من وصولهما لحظيًا للجهاز الآخر.
5. اقترح رمزًا وارفضه من الحساب الثاني؛ يجب ألا تُستهلك محاولة.
6. اقترح رمزًا آخر ووافقت عليه أغلبية الفريق (لاعبان: الاثنان، ثلاثة: اثنان، أربعة: ثلاثة)؛
   عند الخطأ تُستهلك محاولة واحدة فقط. رفض لاعب واحد لا يُسقط الاقتراح إذا بقيت الأغلبية ممكنة.
7. أغلق أحد التطبيقين ثم افتحه خلال مهلة الاستعادة؛ يجب أن يعود لنفس المقعد.
8. غادر المضيف عمدًا وتأكد من نقل الاستضافة وحفظ تلميحاته للفريق.
9. أكمل الجولات الثلاث وتأكد من تطابق النتيجة لدى الجهازين.

## إدارة الحملة

يلزم حساب يملك صلاحية `competitions.manage`. من لوحة الإدارة افتح
`شفرة الفريق` لتفعيل الحملة التجريبية أو تعطيلها، وضبط المدة وحد المطالبات
وقيمة المكافأة الوهمية، ومراجعة الغرف والمطالبات الأخيرة.

## قيود النسخة الحالية

- لا يوجد نشر إنتاجي أو مكافآت مالية حقيقية.
- مشاركة الغرفة تعتمد على رمز الدعوة؛ الربط العميق يمكن إضافته بعد اعتماد
  نطاق التطبيق النهائي.
- البلاغ والحظر الاجتماعيان يظلان ضمن أدوات المجتمع الحالية ولم تتم مضاعفتهما
  داخل شاشة اللعبة.

## العدالة وسرعة الاستجابة (2026-10-10)

- كل ضغطة (جاهز، تصويت، رسالة) تظهر فورًا على الشاشة ثم يؤكدها الخادم؛ عند
  الرفض تعود الحالة كما كانت مع رسالة واضحة، وعند انقطاع لحظي يُعاد الإرسال
  تلقائيًا بنفس المعرّف فلا يُحتسب مرتين.
- مهلة سماح ثانية واحدة بعد انتهاء وقت الخزنة لرمز أُرسل قبل الصفر وتأخر في الشبكة.
- الإيقاف المؤقت يوقف مؤقت الجولة فعلًا؛ عند العودة يُستعاد الوقت المتبقي.
- نبض الحضور كل 10 ثوانٍ، ولا يظهر اللاعب "منقطعًا" قبل 45 ثانية.
- الرسائل تُفلتر من الألفاظ المسيئة، ولا يمكن دخول غرفة فيها لاعب بينك وبينه حظر.
